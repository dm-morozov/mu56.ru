# Приёмка текущей локальной версии — 6 октября 2026

Проверена отдельная копия `.local/final-acceptance-20261006`, извлечённая
из свежего source.zip. SHA256 всех frontend/backend-файлов снимка совпали
с текущей рабочей папкой до проверки. Это проверка рабочей версии, а не
всех изменений автоматически принятого Git-коммита.

## Результаты

- Зависимости frontend установлены offline с frozen lockfile; production
  build и отдельный TypeScript завершились успешно.
- HTTP SEO-проверка прошла для 72 страниц: canonical, метаданные,
  структурированные данные; индексация выключена, sitemap пуст.
- Browser E2E: «Полный Расколбас» 9400 + второй аниматор 8800 + звук 2000
  = 20200 ₽. Через поиск «паук» выбран Человек-паук. Форма отправлена,
  показано подтверждение; запись найдена только в отдельной восстановленной
  базе `mu56_restore_8610c1bbf54c`. Сохранённый серверный расчёт 20200,
  герой spider-man, второй аниматор и звук совпали с выбором. Согласие
  lead-2026-10-06-v2 и время записаны; тестовый телефон нормализован.
- Маска телефона полностью стирается повторным Backspace; ввод с 8
  успешно принят сервером как +7. Это один проверенный сценарий,
  не исчерпывающая проверка всех способов редактирования/вставки.
- Бамблби + азотное шоу = 12600 ₽; Новый год 50 минут + азотное = 12400 ₽.
  При выборе 31 декабря 18:00 шоу исключено; до корректных даты/времени
  показана подсказка, затем итог 7000 ₽.
- Фотосъёмка открывает анимацию с отмеченным фотографом; отметку можно
  снять, итог возвращается к 3500 ₽.
- Поиск «Гонщик» оставляет одну карточку. Хлебные крошки детальной страницы
  содержат «Главная / Персонажи / Гонщик», ссылка возвращает в каталог.
  Сортировка популярных начинается с Бамблби, Человека-паука, TikTok,
  Капитана Америки, Гонщика, Бэтмена и чёрного Человека-паука.
- Мобильное меню открывается и ведёт в каталог трансформеров. Проверены
  фактические 360 CSS px и 1440 CSS px: горизонтального переполнения
  документа нет; в форме на 360 px scrollWidth равен clientWidth.
  Настройка размера браузера учитывала его текущий масштаб; зафиксирован
  фактический innerWidth, а не только размер override.
- Три актуальные фотографии трансформеров загрузились. Оптимизатор выдал
  WebP: Человек-паук 384 px / 30186 байт с альфа-каналом; Железный человек
  750 px / 42768 байт; Оптимус 750 px / 36590 байт. Это выборочная проверка,
  не измерение всех фотографий. Скриншот и JSON в папке локальной приёмки.
- Проверка состава релиза и `git diff --check` прошли. До этого для того же
  кода прошли 103 теста catalog/leads; без новых изменений они повторно
  не запускались в этом проходе.

## Границы проверки

Backend приёмки работал на 8083, frontend на 3106, Telegram был явно
выключен, worker не запускался. Тестовая запись оставлена в отдельной базе;
не подключать к ней обработчик уведомлений. Рабочие серверы, заявки,
GitHub и домен не изменялись.

Это эмуляция ширины в настольном браузере. Открытие сайта на настоящем
телефоне ранее подтверждено владельцем, но полный проход клавиатуры,
прокрутки и формы на его устройстве этим отчётом не подтверждается.
Публичный HTTPS, серверный автозапуск и публичные Core Web Vitals остаются
следующим этапом. Документы обработки данных требуют окончательной сверки.

Следом: отдельно разобрать и зафиксировать принятые изменения приложения,
не включать незавершённые иллюстрации и документы автоматически. Локальные
CI и исправление резервирования уже сохранены. Push нового проекта
и размещение требуют отдельного прямого указания владельца.
