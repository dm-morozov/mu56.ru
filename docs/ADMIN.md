# Управление заявками

Вход: http://127.0.0.1:8000/admin/leads/lead/

Для первой учётной записи администратора запустите из корня проекта в PowerShell:

```powershell
.\scripts\dev_admin.ps1
```

Задайте логин и пароль локально. Ввод пароля скрыт; его нужно повторить. Поле email можно оставить пустым. Не присылайте пароль в чат. Скрипт загружает настройки отдельной локальной PostgreSQL и запускает стандартный Django createsuperuser; в frontend учётных данных нет.

Открывайте «Ждут первого контакта» для новых обращений или «В работе» для новых/контактированных/обсуждаемых. Согласованные и закрытые заявки доступны отдельно. Поиск работает по имени, телефону, месту, пожеланиям, контакту мессенджера и внутренним заметкам. Для поиска телефона используйте цифры без пробелов, как в сохранённом номере.

В карточке сначала рабочий статус и внутренние заметки, затем контакты и детали праздника. Время указано по Оренбургу. Исходный состав и предварительный расчёт видны ниже. Их нельзя изменить: это снимок на момент заявки. Можно уточнить программу, героя и дополнения после разговора, но это не пересчитывает снимок и не отправляет новое сообщение в Telegram. Итоговую стоимость пока фиксируйте в заметках; отдельное поле согласованной суммы — будущий этап.

В списке можно выбрать заявки и применить «Связались», «Обсуждаем программу», «Заказ согласован», «Закрыть без заказа». Изменения записываются в историю Django и требуют права изменения заявки. Статус «Заказ согласован» означает результат разговора, а не автоматическую проверку свободной даты. Поля даты/времени и заметки заполняются отдельно.

Состояние Telegram показано в списке и подробной карточке. Ручной повтор уведомления — отдельное действие, не результат смены рабочего статуса. Для неопределённой доставки сначала проверьте чат, чтобы избежать дубля. Подробнее: TELEGRAM.md.

## Два героя в программе трансформеров

Основная программа выбирает большого героя и тариф: Бамблби/Оптимус 6200 руб., Железный человек 5800 руб. Поле героя в такой программе — напарник в обычном костюме. Большие герои и новогодняя пара не допускаются вторым персонажем. Можно не выбирать напарника до обсуждения. Несколько больших героев пока согласуются индивидуально по пожеланиям/заметкам без автоматического расчёта. Для обычного пакета поле означает героя анимации; большой герой, несовместимый с пакетом, не сохраняется. Старые некорректные значения не исправляются автоматически: при открытии показано предупреждение, сотрудник выбирает корректное значение.

## Обновление героев без сохранения

При смене программы список героев обновляется сразу. Совместимый выбор сохраняется, несовместимый сбрасывается с пояснением. Обновляются подпись поля и большой герой; доплата второго аниматора отключается вне пакета. Рабочие изменения записываются только кнопкой сохранения; исходный снимок и уведомления не меняются. При ошибке есть кнопка повторной загрузки; сохранение до завершения запроса блокируется. Без JavaScript действует прежний список при открытии и серверная проверка совместимости. Административный endpoint требует права изменения заявок.


## Второй герой в обычном пакете

`offering` определяет программу и базовую цену. В трансформерах `character` — напарник большого героя: два участника уже входят в цену, галочки доплаты нет. В обычном пакете `character` — первый герой, `second_performer` — доплата второго аниматора, `second_character` — его отдельно выбранная роль. При снятии галочки в публичной форме второй герой сбрасывается. Поле можно оставить пустым и согласовать позже. API и админка проверяют совместимость роли и не принимают второго героя без доплаты в пакете. Выбор сохраняется в отдельном поле, исходном снимке заявки и тексте уведомления Telegram.

Карточки шоу после трансформера открывают заявку с выбранной основной программой и одним отмеченным шоу. Доплата включает шоу и работу двух аниматоров, а время шоу добавляется к основной программе. Цены и длительность берутся из каталога; новые суммы не дублируются в текстах карточек.

Звук («Много звука») и фотограф — только дополнения: выбирайте основную услугу, затем отметьте их в поле «Шоу и дополнения». Отдельный заказ этих услуг и повторное добавление звука, уже включённого в пенную программу, не допускаются. Исходный снимок заявки сохраняет подтверждённые тарифы дополнений на момент обращения.
