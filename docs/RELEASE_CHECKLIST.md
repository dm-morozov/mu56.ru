# Проверка состава релиза — 6 октября 2026

## Правила локальной работы с Git

По пожеланию владельца ветки называются по назначению: `local/release-20261006` для локальной версии, `feat/<тема>` для функциональности, `fix/<тема>` для исправления. Префиксы с названием AI-инструмента не используются. Сообщения новых коммитов: `feat:`, `fix:`, `docs:`, `chore:`, `test:` или `perf:` с конкретным описанием результата. Исторические коммиты не переписывать только ради формата; ветку переименовать можно без изменения истории. Не включать секреты, временные отчёты и посторонние изменения; push и работа с production требуют прямого указания владельца.

Проверяется текущая рабочая папка: существующие отслеживаемые файлы и новые файлы, не исключённые из Git. Проверка не выполняет git add, commit, push или публикацию. Текущий Git index и история коммитов не являются проверенным релизом.

```powershell
.\.venv\Scripts\python.exe scripts/check_release.py
```

Приватный отчёт: `.local/release-qa/audit.json`. Скрипт возвращает ненулевой код при проблеме и выводит только путь/тип находки, без значения секрета.
