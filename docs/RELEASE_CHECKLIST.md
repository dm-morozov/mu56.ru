# Проверка состава релиза — 6 октября 2026

Проверяется текущая рабочая папка: существующие отслеживаемые файлы и новые файлы, не исключённые из Git. Проверка не выполняет git add, commit, push или публикацию. Текущий Git index и история коммитов не являются проверенным релизом.

```powershell
.\.venv\Scripts\python.exe scripts/check_release.py
```

Приватный отчёт: `.local/release-qa/audit.json`. Скрипт возвращает ненулевой код при проблеме и выводит только путь/тип находки, без значения секрета.

## Результат проверки

- Обязательные файлы Django/Next.js, lockfile frontend, production settings, deploy requirements, shell-инструкции и оба серверных env-шаблона присутствуют среди кандидатов.
- 86 файлов `frontend/public`, суммарно около 207 МиБ. Проверены 29 статических импортов портретов и 48 уникальных ссылок на public-медиа, включая динамические карты услуг и пакетов. Пропущенных изображений/видео не обнаружено.
- Восьми контрольным приватным/генерируемым путям запрещено попадание в Git. Добавлены исключения `output/`, SQL-дампов и закрытых ключей. `.local/`, `ai-context/`, Django media, зависимости и сборки уже исключены.
- В проверяемых текстах не обнаружены заданные сигнатуры Telegram/GitHub/AWS-токенов, приватных ключей и URL с паролями БД. Значения секретных полей в env-шаблонах пустые. Это эвристическая проверка известных форматов, а не гарантия отсутствия любых секретов.
- Файлов размером 100 МиБ и больше нет. Самый большой файл — новогоднее видео, около 44,5 МиБ. Большие исходные PNG входят в релиз; для посетителей Next.js выдаёт оптимизированные изображения. Размер исходников не равен размеру загрузки страницы.
