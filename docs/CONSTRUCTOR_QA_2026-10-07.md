# Проверка конструктора — 7 октября 2026

Проверена текущая рабочая версия на `http://127.0.0.1:3001/`, Next dev,
с локальным Django и PostgreSQL. В рабочем дереве есть изменения другого
чата: этот отчёт не означает проверку всех страниц или готовность к выкладке.

## Автоматическая проверка

- `python backend/manage.py test leads catalog --noinput`: 107 тестов,
  PostgreSQL, успешно. Создавалась и удалялась отдельная тестовая база.
- `npm.cmd --prefix frontend run typecheck`: успешно.
- Тесты проверяют CSRF, сохранение заявки и серверного снимка цен,
  совместимость героев, пакеты со вторым аниматором, новогодние слоты,
  согласие и очередь Telegram. Transport в тестах подменён, сообщений нет.
- Обнаружен устаревший фиксированный счётчик в тесте отзывов: после импорта
  16 отзывов скрытие одного возвращает 15, а тест ожидал 3. Теперь счётчик
  сравнивается с опубликованными записями; проверки скрытия и отсутствия
  внутреннего source_key сохранены.

- POST из браузера в рабочую локальную базу в этой проверке не отправляли;
  сохранение и ошибки проверены автоматическими тестами на отдельной базе.
- Реальная Android-клавиатура, выбор времени и удаление цифр телефона
  требуют подтверждения владельца на физическом устройстве. Узкий viewport
  не воспроизводит полностью системные окна телефона.
- Стабильность Telegram на VPS и ответ Selectel этой проверкой не подтверждены.
- Production build текущего рабочего состояния прошёл в изолированной
  копии `.local/release-check-20261007/frontend` через `next build --webpack`:
  компиляция, TypeScript и генерация 17 статических маршрутов успешны.
  Копия включает незавершённые изменения другого чата; это не проверка
  отдельного коммита и не замена GitHub CI с обычной сборкой.
- На рабочей странице нового дополнения `extras/pinata` форма получает
  выбранную пиньяту, хотя она отсутствует в списке основных программ.

  соответствующие страницы сейчас принадлежат работе другого чата.
