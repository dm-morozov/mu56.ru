# Старый новогодний сайт

Изучен 2 октября 2026 года. Клон находится в `mu56/`; исходники и настройки публикации не менялись.

## Полезные материалы

React 19, TypeScript, Vite; одностраничный сайт с галереей, ценами, гарантией и буклетом. Есть фотографии пары Дед Мороз / Снегурочка, азотного и серебряного шоу, сладкой ваты и звукового оборудования, варианты для разных экранов, SVG-логотип. Описания поздравлений и предложения для дома, класса и двора пригодятся для новой `/new-year` после сверки с буклетом.

## Сверка условий

Старые тексты содержат фиксированный выезд +500 руб., другие цифры опыта/числа праздников и возраст от года. Новые условия: индивидуальная стоимость выезда, программы от 2 лет. Личный опыт владельца не приписывать всей команде. Старые сведения не копировать автоматически.

В index.html есть Яндекс Метрика (105020810), в public — файл подтверждения Google. Это наличие настроек в исходниках, а не подтверждение работы счётчика или доступа к кабинетам. Проверить перед запуском; в новый сайт сейчас не подключались.

## Публикация и адреса

`.github/workflows/web.yaml` публикует dist в GitHub Pages при push в main или ручном запуске. Workflow не запускался; действующий сайт не менялся.

Старая карта содержит корень и якоря #gallery, #prices, #booklet, #contact. Якоря не являются отдельными серверными страницами и не передаются серверу: обычные HTTP-перенаправления по ним не работают. Перед переключением сохранить старое размещение, проверить фактические публичные URL и внешние ссылки. Новая главная — главная агентства, новогоднее предложение — /new-year; поведение старых якорных ссылок продумать отдельно.

Клон служит источником материалов для переноса. Он не заменяет резервную копию действующего размещения и проверку DNS перед запуском.
