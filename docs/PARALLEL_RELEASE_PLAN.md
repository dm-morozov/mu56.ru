   Extra не должен появляться в меню основных программ. Не менять согласованные
   цены и не создавать дубли услуг.
2. Разделить готовые изменения на понятные коммиты; исключить генерируемый

3. Проверить конечный снимок: тесты, миграции, TypeScript, build, release audit.

   дампом: там уже есть аккаунт владельца и сохранённая заявка.
