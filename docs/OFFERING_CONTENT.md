# Описания услуг и условия площадки

В Django Admin откройте «Предложения», затем нужную услугу. Поля «Описание» и «Требования площадки» управляют текстом страницы. Описание также выводится в карточках шоу, дополнений, трансформеров и пакетов. При следующем открытии страницы берётся актуальный каталог; пересборка фронтенда для правки текста не нужна.

Первичное наполнение из подтверждённого буклета 9.0 и ответов владельца:

```powershell
& .\scripts\dev_postgres.ps1 Load
.\.venv\Scripts\python.exe backend/manage.py seed_offering_content
```

Команда заполняет только пустые поля существующих предложений. Не создаёт услуги, не меняет цены, длительность, доступность или ранее сохранённые тексты. Источник начальных текстов: backend/catalog/offering_content.py. После восстановления/первой установки запускать после seed_catalog.
