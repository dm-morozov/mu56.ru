# Техническое SEO

Сайт формирует HTML на сервере. У разделов, услуг, персонажей и статей есть canonical и поисковые описания. Для основных разделов используются понятные поисковые заголовки; видимые заголовки сохраняют характер дизайна.

Карта `/sitemap.xml` формируется из публичных данных Django при включённой индексации. Она содержит разделы, услуги, персонажей и опубликованные статьи. Скрытые записи и будущие статьи не попадают в неё. Для Бамблби, Оптимуса и Железного человека основной адрес — `/transformers/<slug>`; отдельные карточки персонажей указывают на него через canonical. Галереи доступны и на основной странице услуги. Старые новогодние карточки перенаправляются на `/new-year`.

Текущий результат: 67 доступных страниц, 64 уникальных адреса в карте сайта для режима запуска. Не используются выдуманные даты изменения страниц. Карта сайта помогает роботам обнаружить страницы, но не гарантирует их индексацию: [документация Яндекса](https://yandex.ru/support/webmaster/ru/indexing-options/sitemap).

## Структурированные данные

JSON-LD содержит Organization с названием, телефоном, городом обслуживания и подтверждённым Telegram; Service с подтверждёнными основными тарифами; Article с заголовком, издателем и датой публикации. Адрес офиса, часы работы и рейтинг не придуманы. Символы `<` экранируются, чтобы текст из админки не мог закрыть script-тег.

Разметка соответствует реальному содержимому; она не обещает расширенный сниппет. Отзывы о собственном бизнесе не оформлены как рейтинг для звёзд в выдаче: [правила Google](https://developers.google.com/search/blog/2019/09/making-review-rich-results-more-helpful).

## Режимы

По умолчанию `SITE_INDEXING_ENABLED=false`: страницы имеют noindex, robots.txt запрещает обход, карта сайта пустая. Страница чернового согласия `/privacy` отдельно остаётся noindex и не включается в карту.

Для реального запуска после проверки домена, контента и текста согласия:

```dotenv
SITE_URL=https://mu56.ru
SITE_INDEXING_ENABLED=true
BACKEND_ORIGIN=http://127.0.0.1:8000
```

Перезапустите frontend после изменения переменных. Robots и sitemap динамические и используют режим запущенного сервера. Локальная основная версия на порту 3000 сейчас закрыта от индексации. Режим запуска проверен отдельным процессом, привязанным только к 127.0.0.1:3001; публичный сайт не менялся.

## Проверки

`node scripts/check_seo.cjs` проверяет отсутствие дублей и служебных адресов в карте, тарифы и безопасную сериализацию JSON-LD. Требуется Node.js 24 с поддержкой TypeScript.

`python scripts/check_seo_http.py` обходит актуальные страницы и проверяет HTTP, canonical, описания, robots и JSON-LD. Для отдельного тестового процесса с включённой индексацией: `--base http://127.0.0.1:3001 --indexing`. Это проверка реального HTML, а не проверка регистрации сайта в поисковых системах.

После публикации остаются настройка HTTPS и перенаправлений домена, Яндекс Вебмастер/Search Console, аналитика и проверка внешнего доступа к sitemap. Учётные записи, отправка карты и изменение действующего сайта в этом этапе не выполнялись.
