# Проверка мобильной навигации — 18 октября 2026

Базовая версия: `85bd62f348aeec993ec864b7f9e0aa9106a0dafa`, ветка
`local/release-20261006`. Историческая `main` не используется для текущего сайта.

## Исправления

- Открытие мобильного меню переносит фокус на первую ссылку. Раньше Tab
  после кнопки открытия перескакивал к содержимому страницы.
- Escape закрывает меню и возвращает фокус на кнопку. Выход фокуса или
  нажатие вне шапки закрывают раскрытую навигацию без перехвата фокуса.
- Смена маршрута, включая Back/Forward, закрывает меню. Переход на широкую
  раскладку сбрасывает открытое состояние; исчезнувший мобильный элемент
  не сохраняет фокус.
- Высота прокручиваемой панели учитывает верхнюю информационную полосу
  вместе с шапкой, чтобы последние ссылки помещались на коротком экране.

Цены, состав программ, заявки, аналитика, права и схема развёртывания не меняются.

## Воспроизводимая проверка поведения

При установленных зависимостях frontend:

```sh
npm install --prefix .local/header-tests jsdom@30.1.3 esbuild@0.28.2
node scripts/check_header.mjs
```

Скрипт компилирует настоящий Header и проверяет его с React в jsdom.
Next Link/Image и pathname заменены минимальными адаптерами; запросы,
заявки и внешняя навигация не выполняются. Вспомогательные зависимости
и скомпилированный файл сохраняются в игнорируемой `.local/`.

12 проверок: фокус при открытии, Escape, выход фокуса, нажатие вне шапки,
смена пути и возврат, переход desktop/mobile, выбор ссылки, повторные
открытия, очистка обработчиков после unmount и CSS-ограничения высоты.
Это проверка поведения компонента, не визуальный браузерный тест.

## Браузерные сценарии приёмки

1. 390×640: открыть меню клавиатурой; фокус на первой ссылке, Tab идёт
   дальше по ссылкам. Escape возвращает на кнопку.
2. Открыть меню и нажать вне шапки либо перейти Tab к содержимому:
   меню закрывается, целевой элемент остаётся доступен.
3. Открыть меню, перейти Back/Forward: раскрытая панель не остаётся.
4. Открыть при 390px, перейти к 1024px и обратно: нет старого открытого
   состояния или фокуса на скрытой кнопке.
5. 390×400 и 768×400, страница вверху: прокрутить меню до последней ссылки
   мессенджера; вся ссылка должна быть выше нижней границы окна.
