# Попытка улучшить мобильные 98 баллов — 8 октября 2026

Пользователь прислал публичный PageSpeed от 08:49:05: Performance 98,
Accessibility/Best Practices/SEO 100, FCP 1.7 с, LCP 2.1 с, TBT 20 мс,
CLS 0.001. Оценка экономии главного изображения всего 7.1 КиБ.

Изменения приложения не внесены и не опубликованы. Проверены два варианта
в отдельной production-копии `.local/performance-100-20261008/frontend`.
Текущие чужие изменения рабочего дерева сохранены.

## Условия

Свежий публичный каталог сохранён GET-запросами: 32 персонажа, 21 предложение,
11 статей, 16 отзывов. Локальный сервер снимка только для GET на 8162,
Next start на 3162, аналитика выключена во всех вариантах. Три последовательных
mobile Lighthouse на вариант, simulated throttling, отдельный headless Chrome.
Запуск браузерной исходной проверки частично пересёкся по времени с исходными
замерами; различие preload на десятки миллисекунд не трактуется как выигрыш
или достоверная регрессия. Результаты локального HTTP отличаются от публичного
HTTPS/PageSpeed; сравнивать абсолютные баллы между этими средами нельзя.

| --- | --- | --- | --- | --- |

| experimental.inlineCss | 84 / 86 / 86 | 1962 / 1958 / 1961 | 3940 / 3925 / 3936 | 3936 |
| Responsive AVIF preload | 87 / 89 / 89 | 1862 / 1820 / 1823 | 3793 / 3623 / 3580 | 3623 |

CLS во всех вариантах одинаков: 0.00399. RuntimeError в девяти отчётах отсутствует.

## Отклонённые изменения

1. `experimental.inlineCss: true` поддерживается установленным Next 16.3.7,
   но в текущей реализации дублирует общий CSS в HTML/RSC и теряет отдельное
   кеширование стилей. Сжатый gzip HTML главной: 35214 → 92403 байта.
   Для пакетов: 25491 → 82696 байт; персонажей: 27760 → 84576 байт;
   Нового года: 23816 → 80960 байт. Задержка CSS исчезает из списка запросов,
   но итоговая загрузка становится хуже. Не включать ради чистого аудита.
2. React DOM `preload` для AVIF с теми же imageSrcSet/imageSizes/type/high
   priority: медиана баллов осталась 89. Устойчивое улучшение не подтверждено,
   поэтому лишняя настройка не перенесена в приложение.

Исходная и inline-сборки прошли TypeScript/build, визуальные размеры/отсутствие
переполнения проверены на главной 412/1440 px, packages/characters/new-year
412 px. Форма открывается без горизонтального переполнения, заявки не отправлялись.
Preload-сборка также прошла build/TypeScript. Стандартные предупреждения
Turbopack о выдаче уже подготовленных AVIF без перекодирования сохранены.

## Решение

Не ухудшать фотографии и не вводить два неэффективных изменения ради
последних баллов. Следующая потенциальная работа — разделение общего CSS
по страницам и реально критическим компонентам с проверкой всех маршрутов,
навигации и диалогов. Это отдельный рефакторинг, его польза ещё не измерена.
Текущие публичные 98 и LCP 2.1 с не являются дефектом, требующим такой работы.
Гарантировать постоянные 100 по одному запуску нельзя.

Справка: установленная документация Next `inlineCss.md`,
https://nextjs.org/docs/app/api-reference/config/next-config-js/inlineCss;
https://react.dev/reference/react-dom/preload.
Локальные JSON/снимки — в `.local/performance-100-20261008/`, в релиз не включать.

## Разделение CSS по страницам и компонентам

После разрешения владельца выполнен отдельный локальный рефакторинг.
Общие стили главной сохранены в `globals.css`; стили формы заявки, фотогалереи,
конструктора аниматоров, дополнительных услуг и внутренних страниц перенесены
в отдельные файлы и подключены через соответствующие компоненты/страницы.
Форма загружается динамически вместе со своими стилями. Фотографии, тексты,
цвета, размеры и бизнес-логика не менялись.

Проверка дерева CSS подтвердила сохранение всех селекторов, объявлений и
медиазапросов. Стили `.package-detail`, используемые на главной в ссылках
карточек, оставлены общими. Сохранены исходные поясняющие комментарии CSS.

Изолированная production-сборка использует свежий снимок GET-каталога и
порт 3163; оригинал CSS сохранён в
`.local/css-split-20261008/globals-original.css`. Рабочая база и заявки не менялись.

| Вариант | Performance, три запуска | Медиана FCP | Медиана LCP | Передача CSS главной |
| --- | --- | --- | --- | --- |
| До разделения | 90 / 90 / 90 | 1816 мс | 3536 мс | 19235 байт |
| После разделения | 90 / 90 / 89 | 1815 мс | 3539 мс | 10775 байт |

Объём CSS в сетевом отчёте Lighthouse сократился на 44%. Медиана баллов
и время отрисовки практически не изменились. Это подтверждает уменьшение
загрузки, но не подтверждает достижение публичных 100 или ускорение LCP.
Медиана TBT: 22 → 33 мс, CLS во всех запусках 0.00399. Локальные оценки нельзя
сравнивать напрямую с публичными 98: окружение и сетевой путь отличаются.

Проверены 17 страниц в ширинах 412 и 1440 px и открытая форма заявки
(35 состояний): вычисленные стили и размеры совпали с исходными,
горизонтального переполнения нет. Дополнительно проверены переходы через
Next Link в шесть разделов и обратно на главную без перезагрузки: конфликты
сохраняющихся таблиц CSS не обнаружены. Форма открывается и закрывается.
Фотогалерея открывается, переключает снимок и закрывается по Escape на
412 и 1440 px. HTML главной со сжатием gzip остался около 35 КБ;
дублирования CSS внутри HTML не добавлено.
TypeScript рабочей версии и изолированная production-сборка прошли.

Решение: сохранить локальное разделение CSS как уменьшение объёма загрузки
без обнаруженных изменений оформления. На этапе этой локальной проверки
рефакторинг ещё не был опубликован. Для отката вернуть только перенесённые стили и убрать пять
добавленных CSS-импортов; чужие параллельные изменения не откатывать.
Замеры и снимки сохранены в `.local/css-split-20261008/` и исключены из Git.
