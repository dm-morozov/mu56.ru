# Локальное сжатие фотографии для мобильного экрана

8 октября по запросу владельца проверены четыре варианта AVIF из исходного
PNG, без изменения кадра и разрешения: quality 55/50/45/40, effort 9.
Размеры 750px: 60008 / 50892 / 42752 / 35097 байт.
Текущая опубликованная версия 750px: 59085 байт.

Выбран quality 45: 42752 байта, сокращение 27.6%. Вариант quality 40
отклонён как менее осторожный: на увеличенных фрагментах сильнее сглажены
мелкие детали. Просмотрены сравнения при мобильном размере 376×380 и
увеличенные фрагменты лиц и одежды; существенного ухудшения выбранного
варианта при мобильном размере не обнаружено. Это визуальная оценка агента,
не утверждение о математически идентичном изображении.

Дополнительно подготовлен 1080px с теми же настройками: 71942 против
98625 байт, сокращение 27.1%. Его качество также просмотрено.

Новые файлы подключены первым AVIF source только при max-width 600px.
Настройки sizes, object-fit, object-position, высота и исходное кадрирование
сохранены. Для больших экранов старый source остаётся прежним. В мобильном
srcSet оставлен старый 1437px для устройств, которым нужно больше пикселей.

Изолированная production-сборка и TypeScript прошли. В headless Chrome
проверены отдельные холодные загрузки 360/390/412/600/601/1440 CSS px,
включая DPR 1 и 2. Телефоны 360/412 DPR1 выбрали новый 750px;
390/412 DPR2 — новый 1080px; 600 DPR2 — прежний 1437px.
601/1440 DPR1 и 1440 DPR2 выбрали прежние файлы, как предусмотрено.
Переполнения нет, object-position 48% 50% сохранён. Проверены мобильные
скриншоты страницы. Форма и рабочая база не менялись.

Изменения пока локальные; публичный PageSpeed для этого варианта не измерен.
Достижение 100 не подтверждено. Для отката убрать первый source и два
mobile-импорта из home-hero-image.tsx; прежние изображения не перезаписаны.
Кандидаты и визуальные сравнения: `.local/mobile-hero-20261008/`, исключены из Git.
