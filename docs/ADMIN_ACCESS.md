# Доступ владельца к заявкам

7 октября 2026 проверено GET-запросами: `/admin/` перенаправляет на вход,
`/admin/login/` и CSS админки возвращают HTTP 200 через HTTPS. Страница входа
имеет private/no-store. Агрегированный запрос к серверной auth_user вернул
пустой список: учётная запись ещё не создана. Вход владельца пока не проверен.
Ограничение dev по IP сохраняется; доступ с другой сети может вернуть 403.

## Создать учётную запись на действующем тестовом сервере

Владелец запускает в PowerShell из корня проекта:

```powershell
.\scripts\server_admin.ps1
```

Скрипт использует существующий SSH-ключ Selectel и проверку известного ключа
сервера. Открывает интерактивный createsuperuser в контейнере действующего
проекта; не пишет пароль в файл/аргументы/журнал и не меняет существующие
учётные записи. Рекомендуемый логин `dm-morozov`, email необязателен. Введите
свой уникальный пароль дважды, сохраните в менеджере паролей. Пароль не
отображается при вводе. Не отправляйте его в чат и не обходите предупреждение
Django о слабом пароле. Это полноправный аккаунт владельца; не выдавайте его
другим людям. Локальная `dev_admin.ps1` создаёт другой аккаунт в локальной БД.

## Проверить доступ и обработку

1. Войти на https://dev.mu56.ru/admin/ с созданными данными.
2. Открыть «Заявки»: список содержит сохранённые обращения независимо от
   состояния Telegram. Не создавать вымышленную клиентскую заявку только
   ради проверки доступа; пустой список в тестовой среде допустим.
3. Открыть существующую заявку, если она есть: проверить состав, сумму,
   статус обработки и блок «Уведомление Telegram». Ошибка отправки не
   удаляет заявку; связаться можно по оставленным клиентом данным.
4. При FAILED/UNCERTAIN сначала сверить Telegram, затем при необходимости
   выбрать действие повтора. UNCERTAIN может означать уже доставленное
   сообщение. Не повторять уведомление только из-за отсутствия прочтения.
5. После проверки выйти из аккаунта на общем устройстве.

7 октября 2026 владелец подтвердил создание аккаунта `dm-morozov`,
успешный вход и просмотр списка с одной сохранённой заявкой. В списке
уведомление имеет статус «Отправлено»; сумма «Нужно уточнить» допустима
при отсутствии выбранной программы. Контакты и содержимое заявки здесь
не сохраняются. Доступ к списку подтверждён владельцем; изменение заявки
и повтор уведомления в рамках этой приёмки не выполнялись.
Существующий backup базы включает созданный серверный аккаунт; Git и
локальная БД его не содержат. Перезапуск контейнеров не удаляет аккаунт.
