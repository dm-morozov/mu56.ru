# Фотографии персонажей

В Django Admin откройте «Персонажи», выберите героя и найдите блок «Фотографии персонажей». Добавьте фотографию, краткое описание и порядок показа. Галочка «Показывать на сайте» позволяет скрыть фото, сохранив его в админке.

Поддерживаются JPEG, PNG и WebP до 15 МБ. Админка проверяет, что файл действительно является изображением. Оригиналы не сжимаются; оптимизация изображений остаётся отдельным этапом.

После сохранения фото появляется при следующем открытии или обновлении страницы героя. Пересборка React не нужна: страницы получают актуальную галерею из Django. Если видимых фотографий нет, блок галереи не выводится. Новогодняя программа использует фотографии персонажа `new-year-duo`.

## Первичное наполнение

```powershell
& .\scripts\dev_postgres.ps1 Load
.\.venv\Scripts\python.exe backend\manage.py seed_character_photos
```

Команда использует выбранные исходники из `frontend/src/lib/character-gallery.json`, копирует их без изменений в Django media и создаёт записи галереи. Импортированы 27 фотографий для 15 персонажей/программ. Повторный импорт пропускает существующие записи, сохраняя описания, порядок и видимость владельца. Это команда первоначального переноса архива; обычное управление выполняется через админку.

## Хранение и публикация

Файлы находятся в `backend/media/`, каталог исключён из Git. Резервная копия сайта должна включать базу PostgreSQL и этот каталог. Имена загружаемых файлов генерируются случайно; адреса начинаются с `/uploads/`.

Локально Django отдаёт файлы только при `DEBUG=True`, Next.js проксирует `/uploads/`. На Selectel потребуется настроить Nginx или отдельное хранилище для этого пути. Удаление записи не удаляет файл из хранилища автоматически; очистку неиспользуемых файлов нужно выполнять отдельно после резервного копирования. Скрытие управляет показом в галерее, а не доступом к самому файлу по известному адресу.
