## Подтверждённое замечание

**Леди Баг, второе превью**: квадратный кадр с героиней и ребёнком показывается
в карточке3:2 через object-fit:cover, object-position по умолчанию center.
На360 и на пробном450 видно обрезание верхней части головы героини;
маска/лицо героя перестают полноценно читаться. Первый кадр этого дефекта
не имеет. Файл не сломан; полное фото открывается.

Свидетельство: `.local/character-gallery-20261011/ladybug-360-grid.png`.
Это снимок фактического innerWidth360 после коррекции масштаба.

Минимальные варианты для согласования основным чатом:

1. Предпочтительно задать **только этому фото** позицию превью ближе к верху
   (например center top после визуальной проверки). Полное фото оставить
   contain, размер карточек и исходные файлы не менять.
2. Если данные пока не поддерживают индивидуальную позицию, предусмотреть
   необязательный thumbnailPosition у фото с прежним center по умолчанию.
   Поле/адаптер/компонент назначает основной чат; контракт API самостоятельно
   не менялся. Глобальное object-position:top для всех галерей не предлагается.

Перестановка фото не решает обрезание второго превью. Изменять всю сетку,
пересжимать картинки, создавать новые изображения и делать отдельные
кадры для каждого устройства по этой находке не нужно.
