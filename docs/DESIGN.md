# Первый дизайн «Мира Улыбок» — 1 октября 2026

Рабочий локальный сайт: http://127.0.0.1:3000/. Каталог: http://127.0.0.1:3000/characters.

## Визуальное направление

Тёплый светлый фон, тёмные читаемые заголовки, оранжевые кнопки, жёлтые праздничные акценты и пастельные карточки. Шрифты Manrope и Unbounded подключены локально. Сохранён предоставленный логотип. Реальные фотографии праздников показывают эмоции детей; персонажи с прозрачным фоном показаны целиком, без обрезки головы и ног.

Главная ведёт к трансформерам и готовым пакетам. Каталог содержит 35 публичных персонажей и тематических ролей, поиск по имени и категории. На телефоне — две карточки в ряд, раскрывающееся меню и отдельная композиция главной. Женские роли отмечены «Доступность уточняйте». Для ведущего без отдельного портрета используется понятная подпись, без выдуманной фотографии.

## Реализовано

- Главная, каталоги и карточки персонажей, трансформеров, пакетов, шоу и дополнений; галерея, Новый год и контакты.
- React/TypeScript с Next.js; Redux Toolkit управляет выбором и формой. Страницы получают каталог и цены из Django API и возвращают HTML с содержимым.
- Форма сохраняет заявки через API с CSRF и показывает успех только после успешного ответа. Проверено в браузере на локальной PostgreSQL: тестовый пакет `full-party`, снимок цены 9400 ₽.
- 41 предоставленный файл скопирован в `frontend/public/media` без изменения оригиналов. Сжатие отложено по просьбе владельца; измерения скорости до оптимизации не считаются итоговыми.
- Подготовлены заголовки и описания страниц. Индексация выключена до запуска; полный SEO-этап, статьи, аналитика и sitemap впереди.

## Уточнения по дизайну и каталогу — 1 октября

Выезд описан как праздник на площадке клиента: в помещении или на улице. Большие герои используют карточки с фотографией на всю ширину; прозрачные изображения сохраняют композицию в полный рост. В шапке и футере — исходный SVG-змей и текстовое название бренда.

Новый год представлен одной программой «Новогодняя сказка: Дед Мороз и Снегурочка», всегда два героя. Тарифы 15/30/45/60 минут: 3500/4500/5000/6000 ₽. Час со звуком — 8000 ₽. Старые отдельные карточки скрыты, их адреса перенаправляются на /new-year.

У 35 публичных персонажей есть описания; команда seed_character_content заполняет только пустые тексты. Редактировать описания можно в Django Admin. Галереи есть у 15 персонажей/программ и скрываются, если фотографий нет. Галереи управляются через Django Admin и поступают на сайт из API без пересборки фронтенда. Выбранные фотографии архива импортированы в Django командой seed_character_photos. Инструкция: docs/GALLERIES.md.

Скриншоты уточнений: docs/design/revisions/. Production build и 19 backend-тестов прошли.
