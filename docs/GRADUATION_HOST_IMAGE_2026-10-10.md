# Образ ведущего на выпускной

10 октября 2026. По запросу владельца создан полнофигурный образ на основе
его портрета `frontend/public/media/dmitry-morozov-host.webp`.

Итог: `frontend/public/media/characters/graduation-host-dmitry.png`,
1024 × 1536, PNG с альфа-каналом. Проверены прозрачные пиксели вне фигуры.
Исходный портрет сохранён. Использован встроенный imagegen, не CLI.

Промпт создания: сохранить лицо, голубые глаза, причёску, улыбку и естественную
кожу мужчины на исходном портрете; правдоподобная стройная фигура для роста
183 см и веса 77 кг. Современный ведущий выпускного: тёмно-синий костюм,
белая рубашка без галстука, белые кеды, чёрный беспроводной микрофон.
Естественная приветливая поза, полный рост, обе ступни и руки целиком,
мягкое студийное освещение, прозрачный фон, без текста и логотипов.

Финальный уточняющий промпт: сохранить мужчину, лицо, одежду, позу и микрофон
без изменений; убрать фон, ореол, туман и тень за пределами силуэта,
сохранить естественные сглаженные края и прозрачный альфа-канал.

Полное тело синтезировано по описанию: это визуализация образа, не новая
реальная фотосессия. На странице это пояснено. Обещания личного выезда
Дмитрия не добавлены; программу проводит команда.

Подключён к каталогу и подробной странице через characterImage;
для этого персонажа применяется contain, как для вырезанных персонажей,
прежнее увеличение портрета отменено. Статический импорт даёт URL с хешем.

TypeScript прошёл. В браузере каталог показывает фигуру на фоне карточки
без прямоугольного фона; подробная страница загрузила изображение.
Снимок: `.local/graduation-host-suit-page-20261010.jpg`.
Цены, база и другие персонажи не менялись. На production не опубликовано.
