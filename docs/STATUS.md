- Форма подключена к API через прокси Next.js, сохранены завершающие слеши Django и CSRF. Тестовая заявка «Проверка дизайна (тест)» сохранена только в локальной базе, пакет `full-party`, снимок цены 9400 ₽; сообщений не отправляли.
- Проверены мобильное меню, поиск (два результата по «паук»), категория супергероев (9), пустой результат и успешная отправка формы. Production build и TypeScript прошли, повторно прошли 18 backend-тестов на PostgreSQL. Индексация локального прототипа выключена.
- Окружение `.venv` на Python 3.12.14, Django 5.2.17, Psycopg 3.3.6, Django REST Framework 3.18.1.
- Модели персонажей, предложений, тарифов, этапов пакетов и каналов связи.
- Русская Django Admin, фильтры, поиск, редактирование тарифов и этапов пакетов.
- Миграция и идемпотентная команда `seed_catalog`: 35 публичных персонажей/тематических ролей, 21 предложение, все пять пакетов.
- Подтверждённые цены буклета и округлённые доплаты сохранены. Дополнения без согласованных цен остаются без тарифа.
