# Перенос на mu56.ru

Владелец прямо разрешил перенос на mu56.ru; muxa6.ru был ошибкой распознавания.

Подготовлены deploy/docker/edge-production-http.conf и
edge-production-https.conf. HTTP-конфигурация установлена на VPS, nginx -t
прошёл, nginx перезагружен. Существующая закрытая dev-конфигурация сохранена.
HTTPS-конфигурация пока не включена: нужен сертификат обоих имён.

Остаток переключения:

1. В DNS оставить одну A корня mu56.ru → 161.104.32.37 вместо четырёх
   GitHub Pages A. Удалить четыре GitHub Pages AAAA: IPv6 этого VPS не настроен.
   www CNAME заменить на mu56.ru. TXT проверки Яндекса сохранить.
2. После проверки DNS выпустить сертификат mu56.ru и www.mu56.ru через
   certbot webroot /var/lib/letsencrypt. Проверить автоматическое продление.
3. Сохранить приватные серверные конфигурации для отката. Обновить SITE_HOST,
   разрешённые Django hosts/CSRF origins и frontend SITE_URL/индексацию.
   Перед включением проверить robots, sitemap и HTML robots/canonical:
   статическая сборка может сохранять метаданные времени сборки.
4. Включить HTTPS-конфигурацию с редиректом www → mu56.ru; nginx -t,
   затем reload. Dev сохранить закрытым и без индексации либо сделать
   закрытый переход на основной сайт без отдельного набора контейнеров.
5. Проверить HTTP/HTTPS и www, страницы/API/media, админку, CSRF, сохранение
   согласованной заявки и доставку уведомления. Не считать перенос выполненным
   только по успешному DNS или ответу главной страницы.

Для отката вернуть прежние DNS GitHub Pages и предыдущие конфигурации/
образы приложения. Учитывать кеш DNS; базу и Docker volumes не удалять.
Прежние записи DNS зафиксированы в истории работы; старый проект сохранён
в проверенном архиве.

## Выполнено 7 октября 2026

Владелец заменил DNS. Сертификат mu56.ru/www выпущен до 5 января 2027,
Certbot настроил продление. Основной HTTPS включён; www и HTTP возвращают
308 на https://mu56.ru с сохранением пути. Закрытый dev возвращает такой же
переход и сохраняет noindex. Отдельного второго приложения не создано.

Прежние настройки сохранены приватно на VPS:
/srv/projects/mu56/domain-switch-20261007T200057Z.
SITE_HOST, Django hosts/CSRF и frontend SITE_URL обновлены. Индексация включена.
Главная, characters, packages, robots, sitemap, offerings API и admin/login
вернули 200. HTML основных страниц содержит index/follow и canonical mu56.ru;
sitemap непустой, robots исключает API/admin и документы обработки данных.

Контроллер выкладки теперь берёт Host из SITE_HOST, разрешая только mu56.ru
или dev.mu56.ru. Семь тестов контроллера прошли. Изменение установлено на VPS;
будущая выкладка не должна требовать старого dev Host.

HTTPS с cookie CSRF и Origin https://mu56.ru: HTTP 201. Проверка не является
повторной визуальной приёмкой на телефоне. До теста очередь: два SENT, прочие
статусы нулевые. Реальные клиентские данные и секреты в этот отчёт не включены.
